# Voice unification constitution

Project principles and mandatory gates. Reference rather than duplicate them.
Document checks do not prove runtime acceptance.

## Principles

1. Intent governs; prior art contributes goals/test ideas, never implementation
   mandates. New selections need current justification.
2. Platform names identify scope. Historical stack names belong in labeled
   references; quarantine covers proposed replacements and unnamed architecture too.
3. VoiceInk stays independent; macOS evidence neither passes nor blocks other
   targets. Android remains required when deferred.
4. Compatible provider/model swaps use configuration alone; new protocols require
   an explicit design change.
5. Failures are visible. Restore armed idle only if previously armed and usable;
   disarm, denied permission, and invalid configuration take precedence.
6. Acceptance tests observable outcomes. Public criteria/IDs guide implementation;
   private cases remain separate.
7. Archives stay read-only references; preserve local work and provenance.

## Mandatory gates

- **G1 Quarantine:** scan active documents/tasks for inherited stack choices;
  review decisions for unnamed inheritance. Label historical references. Zero
  matches alone do not establish sound derivation.
- **G2 Platform honesty:** record target-specific evidence without macOS
  substitution. Untested or unsupported required behavior stays open.
- **G3 Eval separation:** private cases/expected results stay outside the repo;
  public SPEC/EVAL criteria remain here. Check all twelve bindings before claiming
  readiness. A path proves no access isolation; no new isolation infrastructure
  is required.
- **G4 License:** MIT root (live lineage) and required notices present;
  admitted source/dependency provenance reviewed. No AGPL material enters the
  implementation tree; historical references are permitted.
- **G5 Preparation:** generate tasks only after constitution, specification,
  clarification, plan, and analysis pass with recorded evidence. Record gate
  result, evidence, and limits; missing/unrun checks never become passes.
